# High-Stakes Apparatus

Load this for legal, medical, financial, safety, policy, or other high-impact work.

## Additional Requirements

- Use full source logs: queries, databases, inclusion/exclusion criteria, and rejected candidates.
- Separate provenance from confidence on every load-bearing claim.
- Include probability bands inline when probabilities are asserted.
- Present competing hypotheses when sources conflict; do not count sources as votes.
- Add "what would change this conclusion" to the lead or conclusion section.
- Prefer primary and official sources; use secondary summaries only as navigation.
- Stop if the user asks for regulated advice beyond research support.

## Confidence

Use only `high`, `med`, and `low`, and explain the reason in the same row when a claim matters.

## Deletion Rule

If refetch contradicts a claim, delete the claim. Do not preserve it as `[U]`.
